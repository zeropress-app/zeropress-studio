# Body preview and permalinks

In the Post or Page editor, choose **Preview** to view the current title and
body, including changes not yet saved. The preview supports HTML, Markdown,
and plain text. Use **Desktop** or **Mobile** to change its width.

The preview uses the same content renderer as ZeroPress builds, including code
highlighting and table formatting. It uses a neutral stylesheet: the published
site's theme, menus, widgets, and custom code are not reproduced. Scripts and
external embeds do not run, and links do not navigate inside the preview.
Select a link to inspect its address and whether it opens in a new window.
Embedded content appears as a card with its title and source address. These
values reflect the content renderer's output; addresses remain selectable text.
Relative media URLs use the saved permalink, or the site URL for new documents.

**Permalink** opens a saved, published document's public URL in a new tab.
A saved draft shows a non-clickable **Planned permalink**. Changes to the slug
or document status update this address after saving. The address follows the
site's routing settings; displaying it does not confirm that the public site
has been deployed.
